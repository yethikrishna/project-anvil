## New Features

### Conversational Search

Ask questions about your workspace in natural language. The search engine finds relevant documents, emails, and files across all apps, then generates an answer with source citations.

### Real-time Error Tracking

`@anvil/error-tracking` captures errors with:
- Global error handlers (onerror + unhandledrejection)
- React ErrorBoundary with fallback UI
- Breadcrumb trail (navigation, clicks, XHR, console)
- Error deduplication with fingerprinting
- Sentry-compatible export format

### Security Headers

All apps now include A+-grade security headers:
- CSP with per-request nonces
- HSTS with preload
- Permissions-Policy
- Cross-Origin headers

## Improvements

- Rate limiting on all endpoints via `@anvil/rate-limit` (token bucket)
- "Did you mean" typo correction in search
- Mobile gesture navigation improvements

## Bug Fixes

- Fixed collaborative cursor positions in Docs
- Resolved WebSocket reconnection edge case in Shared Worker
