# Project Anvil — Trend Report: 2026-05-21

## 1. Core Library Updates

### Tiptap 3.0 Stable (July 2025) + 2026 Roadmap
- Full SSR/server-side rendering without DOM
- JSX support in `renderHTML` methods (React/Vue)
- Static Renderer (`@tiptap/static-renderer`) — render to HTML/Markdown outside editor
- `@floating-ui/dom` replaces Tippy.js for popovers
- Previously pro features now open-source: Drag Handle, Emoji, Math, File Handling
- **Hocuspocus 4** stable (March 2026) — collaboration server upgrade
- 2026 roadmap: Server AI Toolkit, Decorations API, bidirectional Markdown in core
- **Action**: Upgrade Phase 4 (Docs Clone) from Tiptap 2 → 3; adopt Static Renderer for server-side document previews; evaluate Hocuspocus 4

### MapLibre GL JS v6 Pre-releases
- Drops WebGL1 (WebGL2 only) — better perf, fewer bugs
- ESM-only distribution (no UMD/CJS bundles)
- 3D terrain performance improvements
- `terrainSkirtLength` option for terrain + transparent backgrounds
- Nested objects in GeoJSON sources
- **Action**: Plan Phase 6 (Maps Clone) upgrade to v6 when stable; switch to ESM imports

### Meilisearch 1.15–1.16

- 1.16: Multi-modal embeddings via Fragments API (text + images), Exports API, sorting on documents API
- Composite embedders and embedding cache improvements
- **Action**: Upgrade Phase 7 (Search Clone) to latest Meilisearch; add Conversational Search for document Q&A; evaluate multi-modal for image search

### Next.js & React
- Next.js 16 shipped Oct 2025 (Turbopack stable, React Compiler support)
- React 19.1.x stable
- View Transitions API integration in React (moved from experimental to Canary)
- **Action**: Plan upgrade path from Next.js 15 → 16 for all apps

## 5. Security

### RFC 9700 (Jan 2025) — OAuth 2.0 Security BCP
- PKCE mandatory for all public clients (already implemented ✅)
- Sender-constrained tokens via DPoP (RFC 9449) or mTLS
- Pushed Authorization Requests (PAR) for high-security
- Exact redirect URI matching (no wildcards)
- CSP Level 2+ on all auth endpoints
- **Action**: Audit Phase 2 auth layer against RFC 9700; add DPoP support; tighten CSP

### Supply Chain Security
- GitHub breach via malicious VSCode extension (3,800 repos) — HN front page May 2026
- OIDC federation for CI/CD (no stored secrets)
- SBOMs, dependency scanning, signed artifacts
- **Action**: Add `npm audit` + SBOM generation to CI pipeline; pin all dependency versions
