# Research Report — 2026-05-20

## 1. CRDT & Real-Time Sync

### Loro 1.0 (Sept 2025) — Major new CRDT library
- **Rust + WASM + Swift** — native perf with JS bindings
- Rich data types: text, lists, maps, movable trees
- Git-like DAG history with branches, merges, time travel
- 10–100× faster document imports vs prior versions (LSM-inspired block storage)
- Incremental sync via export/import (2-round eventual consistency)
- Built-in undo/redo, shallow snapshots
- **Verdict**: Strong candidate to replace Yjs for the Docs clone. Richer merging algorithms (Fugue/Eg-walker), built-in versioning, and superior import performance. Worth prototyping.

### Yjs ecosystem updates
- Yrs (Rust port) continues regular releases
- Still dominant for mature editor integrations (Tiptap, ProseMirror, CodeMirror)
- **Verdict**: Keep Yjs for now; evaluate Loro for Phase 2 rewrite or new collaborative features.

**Refs**: [loro.dev/blog/v1.0](https://loro.dev/blog/v1.0), [discuss.yjs.dev](https://discuss.yjs.dev/t/yjs-vs-loro-new-crdt-lib/2567)

## 2. Stalwart Mail Server & JMAP

### Stalwart v0.14.0 (Oct 2025) — Full JMAP Collaboration
- **JMAP for Calendars** (draft-ietf-jmap-calendars / JSCalendar)
- **JMAP for Contacts** (RFC 9610 / JSContact)
- **JMAP for File Storage** (draft-ietf-jmap-filenode)
- **JMAP Sharing** (RFC 9670) — fine-grained permissions for mailboxes, calendars, contacts, files
- First JMAP server to support entire JMAP collaboration protocol family
- v0.15.x/0.16.x: Rewritten JMAP-based Web UI, CLI tools, schema stabilization toward v1.0

**Verdict**: Stalwart now provides calendar + contacts + file storage over JMAP. The Gmail clone could expand into a full workspace client with calendar integration. File storage JMAP could supplement Drive clone for email attachments.

**Refs**: [stalw.art/blog](https://stalw.art/blog/), [GitHub changelog](https://github.com/stalwartlabs/mail-server/blob/main/CHANGELOG.md)

## 3. Meilisearch — Hybrid Search & AI

### v1.13 (Feb 2025) — Hybrid/Vector declared stable
- Vector store (Arroy/LMDB backend) + hybrid search no longer experimental
- Multiple embedders per index (OpenAI, HuggingFace, REST, user-provided)
- CUDA acceleration support
- Improved hybrid scoring with affine transformations (outperforms traditional rank fusion)

### 2026 Roadmap
- **Hybrid by default** — simpler setup, AI-generated document templates
- **Unified AI Gateway** — embedding/reranking with caching, retries, auth
- **Own embedding models** — purpose-built for Meilisearch
- **Serverless indexes** (Q3 2026) — inactive indexes to S3, wake on query
- **Distributed search/sharding** groundwork started

**Verdict**: Current hybrid search setup in Search clone is solid. Consider upgrading to v1.13+ for production stability. Serverless indexes could reduce hosting costs for low-traffic deployments. AI Gateway could simplify the embedding pipeline.

**Refs**: [meilisearch.com/blog/meilisearch-1-13](https://www.meilisearch.com/blog/meilisearch-1-13), [2026 roadmap](https://www.meilisearch.com/blog/2026-march-roadmap)

## 4. SSO/IAM — Authentik Updates

### Authentik 2025.2 → 2026.2 highlights
- **SAML + OIDC Single Logout (SLO)** — back/front-channel (2025.10)
- **Redis dependency removed** (2025.10) — simpler deployment
- **SCIM provider improvements** — policy-based user filtering, selective group sync (2026.2)
- **WS-Federation support** — for Windows/SharePoint apps (2026.2 Enterprise)
- **Object Lifecycle Management** — scheduled compliance reviews (2026.2)
- **Shared Signals Framework (SSF)** — Apple Business Manager support (2025.2)
- **"Impossible travel" / GeoIP checks** via policy (2025.2)
- **Remote Access Control (RAC)** — moved to open source (2025.2)
- **Telegram social login** source (2025.10)

**Verdict**: Authentik has matured significantly. If Anvil ever migrates from Keycloak, Authentik is the top choice — cleaner UI, simpler Docker deployment, no Redis dependency, and now has SLO. Consider for Phase 2 or as an alternative auth option.

**Refs**: [goauthentik.io/blog](https://goauthentik.io/blog/)

## 5. Drive Alternatives

### Seafile — Performance-focused
- Block-level syncing, fast with large files, lightweight
- Lower resource usage than Nextcloud
- Built-in markdown editor

### Syncthing — P2P decentralized
- No central server, peer-to-peer file sync
- Maximum privacy, great for personal use

**Verdict**: Current MinIO + materialized path approach is fine for the portfolio project. For a production-oriented rewrite, Seafile's sync engine could be worth studying for the desktop/mobile sync client.

## 6. YouTube Alternatives

### PeerTube — Federated video platform
- ActivityPub federation, WebTorrent P2P streaming
- Live streaming support, playlists, comments
- True YouTube replacement for self-hosted video

### TubeArchivist — YouTube archiver
- yt-dlp based downloading, Elasticsearch metadata indexing
- Full-text search across video metadata/subtitles
- Watch/unwatch tracking, channel subscriptions

**Verdict**: For a real self-hosted YouTube clone (not API proxy), PeerTube is the reference implementation. TubeArchivist's Elasticsearch approach to video metadata search could inspire the Search clone's video tab.

## 7. Deployment Cost Optimization

### Oracle Cloud Always Free (top pick)
- **4 OCPU Arm + 24 GB RAM** — perpetual free
- 200 GB block storage, 10 TB/month egress
- Runs Docker, PostgreSQL, Redis, multiple apps
- ARM architecture; occasional capacity issues

### Coolify v4.0 (April 2026) — Self-hosted PaaS
- Vercel/Heroku alternative running on any VPS
- Push-to-deploy from GitHub, preview environments, auto SSL
- 280+ one-click Docker services
- Free forever (self-hosted), $5-20/month VPS replaces hundreds in Vercel bills
- v4.1.0 (May 2026) with Railpack build pack support
- **Caveat**: Had critical CVEs in early 2026, all patched — keep updated

**Verdict**: For zero-cost deployment, Oracle Cloud Always Free is unmatched (4 ARM cores, 24 GB RAM). Coolify on a cheap Hetzner VPS could replace Vercel + Render entirely, giving unified deployment with push-to-deploy. Consider adding Coolify deployment option to Phase 10.

## 8. React/Next.js Component Libraries

### shadcn/ui ecosystem (dominant in 2026)
- **shadcnblocks.com** — 1,625+ blocks + 1,189 components + 15 templates
  - Productivity-focused: Todo, Kanban, Calendar, Dashboard shells, Data Tables
- **Official shadcn/ui Blocks** — free foundational blocks at ui.shadcn.com/blocks
- **shadcn.io** — AI-native blocks optimized for Cursor/v0.dev workflows

### Recommended patterns for Anvil
- Dashboard shells (sidebar + cards + charts) → unified nav
- Kanban views → task/project management
- Command menu (Cmd+K) → universal search across all Anvil apps
- Data tables with sorting/filtering → Drive, Gmail, Docs lists

**Verdict**: If Anvil doesn't already use shadcn/ui, it should. The blocks ecosystem provides production-quality productivity UIs that would elevate all 6 clones. Add shadcnblocks evaluation to the shared UI library phase.
