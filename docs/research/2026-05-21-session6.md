# Research Report — 2026-05-21 Session 6 (05:42 UTC)

## 1. CRDT Libraries

### Loro 1.x — Rising Star
- **Loro** (Rust + MoonBit port called "Lomo") is the most notable new CRDT library in 2026.
- Built on the **Eg-walker algorithm** — significantly faster for large document imports (10-100× vs Yjs for re-imports).
- Rich collaborative types: text, lists, maps, movable lists, trees.
- Built-in **Git-like version history** — branch, merge, time-travel.
- Binary-compatible between Rust and MoonBit runtimes.
- **Verdict**: Already tracked in Phase 12. Worth prototyping as Yjs replacement in Docs clone for the versioning story alone.

### Yjs — Still King
- Most mature JS/TS CRDT ecosystem. Powers most production collaborative editors.
- Rust core (`y-crdt`) with multi-language bindings.
- **Verdict**: Keep as default. Loro is the upgrade path for versioning-heavy features.

### Automerge 2.0
- Research-grade, best for JSON-like documents.
- Less relevant for rich-text editors vs Yjs/Loro.
- **Verdict**: Low priority.

## 4. SSO/IAM Landscape

### Authentik 2026.2 (Feb 2026)
- Object Lifecycle Management (Enterprise only) — compliance reviews/attestations.
- WS-Federation support (Enterprise) — for Microsoft environments.
- SCIM improvements — policy-based sync filtering, full group import.
- Endpoint Devices + FleetDM integration (Enterprise).
- Backend updated to Python 3.14.
- Dropped Redis dependency.
- **Open-source core remains strong**: OIDC, SAML, SCIM, LDAP, MFA all included.

### Keycloak vs Authentik (2026 Consensus)
- **Authentik** is winning mindshare for greenfield/self-hosted projects due to simpler deploy, no Redis, cleaner UI.
- **Keycloak** still better for complex enterprise federation (LDAP, Kerberos, identity brokering).
- **Zitadel** (Go-based) emerging as third option — cloud-native, built-in multi-tenancy.

### Other Alternatives
- **Authelia** — lightweight forward-auth proxy for simple SSO + MFA. Good for homelab.
- **Ory Stack** (Kratos + Hydra) — API-first, headless, microservices-friendly.
- **FusionAuth** — developer-friendly, passkey support.
- **Better Auth** / **Hanko** — emerging passwordless/passkey focus.

**Action**: Authentik is the recommended Keycloak replacement for our use case (simpler Docker deploy, no Redis, good OIDC/SAML). Zitadel worth evaluating as option 3.

## 5. Deployment — Free Tier & PaaS

- Push-to-deploy, automatic HTTPS, 280+ one-click services.

### Other Free Options

## 6. Maps — Open-Source Alternatives

### Protomaps + PMTiles (Recommended 2026 Approach)
- Single ~120 GB PMTiles file = entire planet OSM data.
- Serve statically (S3/any web server) via HTTP range requests. No tile server needed.
- Frontend: MapLibre GL JS.
- Style with Maputnik.
- **Massively simpler** than PostGIS + tile rendering stacks.
- **Action**: Evaluate PMTiles for Maps clone deployment — could eliminate the need for a running tile server in production.

### OpenFreeMap
- Fully open-source map hosting. Self-host or use public instance.
- GitHub: hyperknot/openfreemap

### Dawarich / Reitti
- Google Timeline (location history) replacement.
- Pairs well with mapping stacks.
