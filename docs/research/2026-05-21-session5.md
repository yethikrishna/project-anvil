## 1. MinIO Community Edition — Maintenance Mode; Alternatives

### Situation
MinIO's community edition has effectively entered maintenance mode (late 2025/early 2026). Features removed, limited updates, licensing shifts. This directly impacts Phase 1's Docker Compose setup.

### Alternatives

#### SeaweedFS (Go, Apache 2.0)
- Drop-in S3-compatible replacement
- **3–4× faster** than MinIO for small-file uploads
- Handles billions of files, low operational overhead
- Good K8s/Helm support, single-node to large clusters
- Best for production workloads with small-to-medium files

#### Garage (Rust, AGPL-3.0)
- Lightweight, geo-distributed, self-hosted-first
- Low resource usage, strong consistency
- Best for resource-constrained or multi-site deployments
- AGPL license consideration for commercial use

#### Cloudflare R2 (managed)
- S3-compatible, **free egress forever**
- 10 GB storage free, 1M writes + 10M reads free per month
- No self-hosting needed, global edge distribution

### For Anvil
Phase 3 uses MinIO for BLOB storage. Options:
1. **SeaweedFS** — best self-hosted drop-in replacement (Apache 2.0, faster)
2. **Cloudflare R2** — best for demo/portfolio deployment (free egress, zero ops)
3. Keep MinIO for now if it works, but note it's no longer actively developed

**Action**: Add SeaweedFS as MinIO replacement option. Add Cloudflare R2 as the managed storage option for demo deployments (pairs with Phase 10's Vercel frontend).

## 2. Cloudflare Free Tier — Complete Stack for Demo Deployment

### What's Free (per month, no time limit)
| Service | Free Tier | Best For |
|---------|-----------|----------|
| **Workers** | 100K req/day | Edge API gateway, auth middleware |
| **R2** | 10 GB + 1M writes + 10M reads, free egress | File storage (Drive clone) |
| **D1** | 5 GB + 5M reads/day + 100K writes/day | SQL database (all apps) |
| **KV** | 1 GB + 100K reads/day | Session cache, config |
| **Pages** | Unlimited sites, 500 builds/month | Frontend hosting |

### Anvil Demo Stack on Cloudflare Free Tier
- **Pages**: All Next.js frontends (static/SSG)
- **Workers + Hono**: API gateway, auth middleware, rate limiting
- **R2**: Drive BLOB storage (10 GB free, no egress cost)
- **D1**: SQLite database for all app metadata (5 GB free)
- **KV**: Session/token caching

Total cost: **$0/month** for a portfolio demo. This is simpler than Oracle Cloud Always Free (no VM management) and pairs perfectly with the Hono edge gateway from session 4.

**Action**: Create a "Cloudflare Free Stack" deployment guide as an alternative to Vercel + Render + Neon. Use D1 instead of Neon for demo, R2 instead of Supabase Storage.

## 3. React Aria Components (Adobe) — Accessible Headless UI

- 50+ unstyled, accessible components (headless)
- Full W3C ARIA Authoring Practices compliance
- Keyboard navigation, screen reader support, voice control, mobile touch
- Drag & drop, virtualization, table column resize, date picker, tree views
- v1.17.0 (April 2026): expandable table rows, horizontal virtualization, major bundle reductions

### Notable 2025–2026 Additions
- Multi-select ComboBox and Select
- Autocomplete (GA)
- Drag & drop in Tree (keyboard + screen reader accessible)
- Enhanced animations, origin-aware overlays
- React 19 compatible

### For Anvil
Phase 19 has accessibility items (WCAG 2.2, screen reader mode, voice control). React Aria provides the foundation:
- Accessible date pickers (Calendar app)
- Accessible combo boxes (Search autocomplete)

- Accessible drag & drop (cross-app file sharing)

**Action**: Evaluate React Aria Components as the accessibility layer for `@anvil/ui`. Pairs with shadcn/ui (which uses Radix) — could supplement or replace Radix primitives where accessibility is critical. Phase 19 compliance becomes much easier.
