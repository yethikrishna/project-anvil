## Gap Analysis: What's NOT in the 40 Phases

### 1. Agentic AI (Autonomous, not just Copilot)
Current: AI Copilot sidebar (reactive, suggests/edits on request).
**Gap**: Autonomous AI agents that act independently:
- **Email agent**: Reads inbox, drafts replies, categorizes, and archives — user just reviews/approves
- **File agent**: Watches Drive, auto-organizes into folders, tags, detects duplicates, generates thumbnails
- **Schedule agent**: Negotiates meeting times with other agents (protocol for agent-to-agent scheduling)
- **Doc agent**: Generates first drafts from outlines, researches and inserts citations, formats to style guide
- Resume line: "Built autonomous AI agents that manage email triage, file organization, and scheduling with human-in-the-loop approval"

### 2. Protocol-Level Federation (Build on Open Protocols)
Current: Federated architecture at the app level (microservices).
**Gap**: Protocol-level federation using open internet standards:
- **ActivityPub** for social feed / sharing (interoperable with Mastodon)
- **Matrix protocol** for chat (interoperable with Element/Slack bridges)
- **AT Protocol** for portable identity (DID-based, portable social graph)
- **WebFinger** for user discovery across instances
- Resume line: "Built on open federation protocols (ActivityPub, Matrix, WebFinger) enabling cross-platform interoperability"

### 3. Speculation Rules API (Instant Navigation)
Current: View Transitions for animations, but no prefetch/prerender.
**Gap**: Use `<script type="speculationrules">` to prefetch/prerender pages:
- Prerender the top 3 likely next pages based on user behavior
- Prefetch Drive file previews on hover
- Prerender search results page while user is typing
- Resume line: "Implemented Speculation Rules API for sub-zero navigation latency with behavioral prefetch heuristics"

### 4. File System Access API (Native File Integration)
Current: Browser-based upload/download.
**Gap**: Use File System Access API for native OS file integration:
- Open files directly from native filesystem into Anvil Docs
- Save Anvil docs directly to local filesystem
- Watch local folder for changes → auto-sync to Drive
- Resume line: "Integrated File System Access API for native OS file open/save with auto-sync"

### 5. WebNN (Hardware-Accelerated Browser ML)
Current: ONNX/WASM for client-side ML inference.
**Gap**: WebNN API delegates ML to GPU/NPU hardware:
- Face clustering in Photos via hardware-accelerated inference (10-100x faster than WASM)
- Real-time background blur in video calls without TensorFlow.js overhead
- On-device document OCR at camera capture speed
- Resume line: "Used WebNN API for hardware-accelerated on-device ML inference (face clustering, background segmentation)"

### 6. Scheduled Email Sending + Email Templates
Current: Gmail has compose, but no scheduling or templates.
**Gap**:
- "Send later" — compose now, schedule for optimal delivery time
- Reusable email templates with variable substitution ({{name}}, {{date}})
- AI-suggested optimal send time based on recipient's reading patterns
- Resume line: "Built scheduled email delivery with AI-optimized send times and reusable template system"

### 7. Document OCR (Text Extraction from Images/PDFs)
Current: Semantic search via embeddings, but no explicit OCR pipeline.
**Gap**:
- OCR on uploaded PDFs/images → extract text → make searchable
- Tesseract.js (WASM) for client-side OCR
- Extracted text indexed in Meilisearch
- Resume line: "Implemented client-side OCR via Tesseract.js/WASM for searchable PDF and image text extraction"

### 8. Cross-App Canvas (Notion-like)
Current: Whiteboard (Excalidraw) and Docs (Tiptap) are separate apps.
**Gap**: A unified "Anvil Canvas" that embeds any content type as blocks:
- Nest docs, sheets, maps, photos, videos as live-embedded blocks
- `/` command to insert any app content (like Notion)
- Blocks are live — edit a sheet embedded in a doc, changes reflect everywhere
- Resume line: "Built a unified canvas that embeds live instances of every app as interactive blocks"
