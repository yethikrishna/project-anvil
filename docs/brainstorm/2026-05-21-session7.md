# Brainstorm — 2026-05-21 Session 7 (08:06 UTC)

## Novel Feature Ideas

### 1. JMAP-First Workspace Client
With Stalwart v0.16 now supporting JMAP Calendar + Contacts + Files alongside Mail, we can build a **unified JMAP workspace client** — one protocol, one auth, all collaboration data. This is a unique differentiator: nobody else has a JMAP-native PIM suite.

**Implementation**:
- Extend Gmail clone to become "Anvil Mail" — full PIM client
- Add Calendar (JMAP Calendars/JSCalendar), Contacts (JSContact), File storage (JMAP Blob)
- Shared JMAP session across all views
- This is a portfolio *showstopper* — demonstrates deep protocol understanding

### 2. Cloudflare Free Stack Demo Deployment
Ship a complete $0/mo deployment guide using only Cloudflare free tiers:
- **Pages** → all Next.js frontends (static export + edge functions)
- **Workers** → API backends (search, geocoding, auth proxy)
- **R2** → BLOB storage (Drive files)
- **D1** → SQLite database (metadata, users)
- **KV** → session cache, config
- Demo URL: `anvil.pages.dev` — zero-cost, globally distributed

### 3. PGlite Offline Layer
Use PGlite (WASM Postgres with pgvector + PostGIS) as a **universal offline layer**:
- Full SQL + vector search + geospatial queries in the browser
- Sync with server-side Postgres via ElectricSQL or custom replication
- Enables true offline-first Drive, Docs, Mail, Maps
- Uniquely impressive: "Postgres in your browser tab" is a wow moment

### 4. PMTiles Regional Extract Pipeline
Replace the tile server with PMTiles + Protomaps for the Maps clone:
- `pmtiles extract` for demo region (India + US)
- Host on R2 → zero-cost, globally cached
- No tile server to maintain
- Add custom Protomaps themes matching Anvil design system

### 5. Loro CRDT Version Timeline for Docs
Add a **document version timeline** using Loro's built-in Git-like history:
- Visual timeline slider showing document evolution
- Branch and merge documents (like Git branches for text)
- Compare any two versions with semantic diff
- "What did this look like last Thursday?" → instant answer
- Use Loro alongside Yjs: Yjs for real-time editing, Loro for history

## Architecture Ideas

### 11. Monorepo → Multi-Deploy Pipeline
Create a unified CI/CD pipeline:
- Turborepo for monorepo builds (caching, parallel)
- Each app builds independently
- Deploy to: Vercel (frontends) + CF Workers (APIs) + R2 (storage)
- Single `git push` → all apps rebuilt and deployed

### 12. Event-Driven Cross-App Communication
Implement an internal event bus:
- Drive file uploaded → Search index updated → AI tagging triggered → Notification sent
- Calendar event created → Maps route suggested → Email reminder scheduled
- Uses Redis/Valkey pub/sub or CF Queues
- Makes the workspace feel *alive* and interconnected

### 13. Edge-First API Gateway
Use Hono (402K ops/sec, <14KB) as an edge gateway on CF Workers:
- Single entry point for all API traffic
- Rate limiting, auth validation, request routing at the edge
- A/B testing, feature flags
- Caching with CF KV
- Replaces multiple API deployments with one edge function
