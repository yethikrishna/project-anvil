## 1. 🧠 AI-Powered Features (Nobody Else Has These)

### 1a. Anvil AI Copilot (cross-app assistant)
A persistent, context-aware AI sidebar that lives across ALL Anvil apps. It knows what you're working on and can:
- **In Drive**: "Find the contract I sent to Acme Corp last March" → semantic file search
- **In Docs**: "Make this paragraph more professional" → in-document AI editing
- **In Gmail**: "Draft a reply to this thread that confirms Tuesday's meeting" → context-aware email composition
- **In Search**: "Show me results about distributed systems that aren't just Wikipedia" → AI-refined search
- **In Maps**: "Plan a route that avoids tolls and hits a coffee shop halfway" → intelligent routing
- **In YouTube**: "Summarize this 45-min talk and extract key quotes" → video intelligence
- **Tech**: Shared `@anvil/ai` package with provider abstraction (OpenAI, local Ollama, etc.)

### 1b. Semantic File System
Instead of just folders, Drive gets AI-powered tagging:
- Auto-classify documents by type (invoice, contract, resume, photo, etc.)
- Natural language search: "show me all photos from the beach trip"
- Duplicate detection via embedding similarity
- Smart clustering: automatically group related files into "workspaces"
- **Tech**: MiniLM embeddings stored in PostgreSQL `pgvector`, HNSW index for fast ANN search

### 1c. Smart Email Triage (Gmail)
- Priority inbox powered by AI — learns your behavior over time
- Auto-categorization: Newsletter, Transaction, Social, Work, Personal
- "Snooze until referenced" — AI detects time-sensitive patterns
- Thread summarization: "What did I miss in this 47-email thread?"
- Sentiment analysis: flag aggressive or urgent emails
- **Tech**: ONNX model running in WebAssembly for client-side inference

### 1d. Document Intelligence (Docs)
- Auto-generate table of contents from headings
- "Continue writing" — AI autocomplete that matches your style
- Citations & references: paste a URL, AI extracts key facts
- Grammar/style checker with inline suggestions (like Grammarly, but open-source)
- Version diff summary: "What changed between v3 and v5?" → human-readable changelog

## 2. 🏗️ Architecture Innovations

### 2a. Micro-Frontend Shell with Module Federation
The unified navigation shell isn't just an iframe hack — it's a proper micro-frontend:
- Each app (Drive, Docs, Gmail, etc.) is an independently deployable module
- Webpack Module Federation or Vite federation for runtime composition
- Shared dependency deduplication (one React, one Tailwind runtime)
- **Jaw-drop factor**: Deploy a fix to Gmail without touching Drive. Zero-downtime.

### 2b. Edge Computing with Cloudflare Workers / Vercel Edge
- Auth token validation at the edge (sub-10ms auth checks)
- Geographically distributed file metadata caching
- Edge-side search index for instant autocomplete
- Image transformation at the edge (resize, crop, format conversion)
- **Showcase**: "Our search returns results in <50ms from anywhere in the world"

### 2c. Shared Worker Threads + BroadcastChannel
- One WebSocket connection shared across all app tabs (no more 6 tabs = 6 connections)
- Real-time sync via `SharedWorker` + `BroadcastChannel`
- Background sync for file uploads (survives tab close)
- **Showcase**: "Open 10 tabs, still only 1 WebSocket connection"

### 2d. Event Sourcing for Docs
- Instead of just storing current state, store every keystroke as an event
- Time-travel debugging: "Show me exactly what this doc looked like on March 15th at 3pm"
- Branch & merge: create document branches like git branches
- Replay analytics: visualize how a document evolved over time
- **Tech**: Yjs already does this partially; extend with a proper event store

### 2e. Progressive Web App with Full Offline Support
- Service Worker with Workbox for offline Drive access
- Background Sync API for queued email sends
- Periodic Background Sync for email fetching
- Web Share API: share files/links from Anvil to any app
- **Showcase**: "Use Gmail offline on a plane, syncs when you land"

## 6. 🔧 Technical Showcase (Resume Gold)

### 6a. WebAssembly Performance Module
Build something in Rust → Wasm that demonstrates raw perf:
- **Image processing pipeline**: resize, compress, filter images in Drive using Wasm (10-50x faster than JS Canvas)
- **PDF rendering**: custom PDF renderer in Rust/Wasm (faster than pdf.js)
- **Search indexing**: build a full-text search index in Wasm for offline search
- **Tech**: Rust + wasm-pack + wasm-bindgen, published as `@anvil/wasm-*`

### 6b. WebGPU Data Visualization
Replace boring charts with GPU-accelerated visualizations:
- **Drive storage analytics**: real-time 3D treemap of file usage (rotatable, zoomable)
- **Email flow visualization**: GPU-powered particle system showing email patterns over time
- **Search heatmap**: visualize search query patterns on a globe
- **Tech**: WebGPU compute shaders + Three.js WebGPU renderer

### 6c. WebRTC P2P File Sharing
- Share files directly between browsers (no server middleman)
- WebRTC DataChannel for encrypted P2P transfer
- "Drop a file, get a link — recipient downloads directly from your browser"
- Chunked transfer with resume capability
- **Tech**: WebRTC, simple-peer, Web Crypto API for encryption

### 6d. End-to-End Encryption (E2EE)
- Optional E2EE for Docs and Drive files
- Client-side encryption using Web Crypto API
- Zero-knowledge architecture: server never sees plaintext
- Key management with WebAuthn (passkeys)
- **Showcase**: "Even we can't read your data" — huge trust signal

### 6e. Performance Monitoring Dashboard
- Real-time Core Web Vitals across all apps
- Custom performance traces for API calls
- Client-side error tracking (Sentry-like)
- Lighthouse CI integration
- **Showcase**: "We track performance like Google does"

### 6f. GraphQL Federation
Replace REST with federated GraphQL:
- Each app exposes its own subgraph
- Gateway composes them into a single unified API
- One query: `{ me { emails { subject } files { name } calendar { events { title } } } }`
- **Tech**: Apollo Federation / GraphQL Mesh
